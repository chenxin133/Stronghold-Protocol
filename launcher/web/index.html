GitHub 更新订阅

Windows、iPad、Android 使用同一个游戏地址。服务器更新后，无需重新封装或安装。

进入游戏 / Play

游戏服务器 / Server

订阅仓库 / Subscriptions

安装到设备 / Install

请使用服务器的可信 HTTPS 地址。

  • Windows：Edge 或 Chrome → 应用 / 安装此网站。
  • iPad：Safari → 分享 → 添加到主屏幕。
  • Android：Chrome → 安装应用 / 添加到主屏幕。

运行中的对局结束后，服务器才会切换新版。订阅链接也可以添加到 RSS 阅读器。
